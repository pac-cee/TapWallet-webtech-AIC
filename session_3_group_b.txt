    Hibernate
----------------
Hibernate is a Java Framework which is being used during 
data persistance and retriaval , where it's built on top of JDBC, and it
used JPA (Java Persistance API).

Hibernate is an ORM (Object Relation Mapping) technology which is used 
to map Java Object (POJO) to a database Relation / table and vise versa


Steps to configurate Hibernate:
-------------------------------
1. Import / add required dependencies it should be added under pom.xml
    -- Hibernate dependency,
    -- Database driver dependency
2. Configure Hibernate configuration wizard (hibernate.cfg.xml)
    - JDBC Properties/ configuration
        -- JDBC URL,
        -- db username
        -- db password
        -- db_driver
    - Entity Mapping
    - Miscellanious properties:
        --schema mechanimis: hibernate.hbm.2ddl.auto: create, update, create-drop, validate
    -- configuration properties:
        --Dialect 
    
Steps to use Hibernate
---------------------------

1. Create HibernateUtil
2. Create Session
    Session ss = HibernateUtil.getSessionFactory().openSession();
3. Create Transaction: CREATE,UPDATE, DELETE
    Transaction tr = ss.beginTransaction();
4. Perfom Action: CRUD
    ss.save(obj); | CREATE
    ss.update(obj); | UPDATE
    ss.delete(obj); | DELETE
    ss.createQuery(HQL); | READ
5. Commit Transaction: CREATE,UPDATE, DELETE
    tr.commit();
6. Close Session:
    ss.close();
